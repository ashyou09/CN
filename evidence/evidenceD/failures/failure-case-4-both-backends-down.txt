=== Diagnosis & Viva Defense ===
- Boundary Isolation between Edge and Upstream:
  - DNS (UDP 53) succeeds: Name resolved.
  - TCP Handshake (TCP 8443) succeeds: Edge Nginx is running and accepting client sockets.
  - TLS Handshake succeeds: Certificate valid and cipher negotiated.
  - Layer 7 Application Failure: Nginx cannot connect to either upstream server (10.7.6.84:3001 or 10.7.17.147:3002). Nginx returns standard `502 Bad Gateway`.
- Key Viva Principle:
  502 Bad Gateway indicates that an intermediate proxy/gateway server received an invalid or null response from the upstream application server. It pinpoints failure to the application tier, completely exonerating DNS, IP routing, and TLS edge layers.
- Remediation:
  Restart backend servers on Mac 3 and Mac 4:
  On C: cd personC/backendA && npm start
  On D: cd personD/backendB && npm start

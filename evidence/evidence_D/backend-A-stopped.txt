=== Diagnosis & Viva Defense ===
- High Availability / Fault Tolerance Demonstrated:
  Even though Backend Server A (Mac 3) is completely offline, client requests experience ZERO downtime and return HTTP 200 OK.
- Nginx Layer 7 Health Checking:
  When Nginx attempts to proxy the request upstream to 10.7.6.84:3001, it receives a TCP connection refusal or timeout. Nginx increments `fail_count` and immediately retries the request with the next available server in the `backend_pool` (Mac 4 Backend B:3002).
- Key Viva Principle:
  Reverse proxies decouple client access from backend application state. Fault isolation ensures failure in one server does not impact user availability.
- Remediation:
  On Mac 3: cd personC/backendA && npm start
  Once back online and `fail_timeout=5s` expires, Nginx automatically resumes 50/50 round-robin balancing.

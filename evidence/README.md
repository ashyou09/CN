## 📂 Detailed Folder Contents

### 1. `evidence_D/` (Dedicated Person D / Mac 4 Folder)
- Consolidated, sequentially indexed copies of all Person D artifacts.
- Includes `README.md` with complete lab rubric and protocol analysis.

### 2. `lan/` (Task A)
- `mac4-interface-discovery.txt`: Output of `route -n get default`, `ipconfig getifaddr en0`, `ipconfig getoption en0 subnet_mask`, and `ifconfig en0`.
- `ping-from-mac4-to-all.txt`: Execution log of `ping -c 3` from Mac 4 (`10.7.17.147`) to Mac 1 (`10.7.17.94`), Mac 2 (`10.7.3.128`), and Mac 3 (`10.7.6.84`).
- `ping-from-C.txt`: Mac 3 ping results to other machines.

### 3. `dns/` (Task B)
- `dns-client-D.txt`: Consolidated client DNS test from Mac 4 (`dig @10.7.17.94 app.teamX.test A`, `dig @10.7.17.94 api.teamX.test A`, and resolver checks).
- `dns-query-evidence-mac4.txt`: Raw `dig` output confirming `app.teamX.test` and `api.teamX.test` resolve to Edge Mac 2 (`10.7.3.128`).
- `scutil-dns-mac4.txt`: Output of macOS system resolver configuration.

### 4. `load-balancing/` (Tasks C & D)
- `backend-b-local-test.txt`: Port 3002 listener check, local curl tests for all endpoints (`/`, `/api/status`, `/api/cached`), and remote curl from Edge.
- `backend-a-remote-test.txt`: Verification of Backend A cross-LAN reachability.
- `https-load-balancing-evidence.txt`: 6 consecutive requests through `https://app.teamX.test:8443/api/status` proving alternating round-robin backend selection.

### 5. `tls/` (Task E)
- `tls-handshake-curl-verification.txt`: Full verbose `curl -v` log proving successful certificate validation, ALPN HTTP/1.1 negotiation, and TLS 1.3 session establishment without `-k`.

### 6. `caching/` (Task F)
- `caching-and-304-evidence.txt`: Step 1 initial fetch showing `Cache-Control: public, max-age=60` and `ETag`, and Step 2 conditional GET with `If-None-Match: "39-jxvt8kclwpAy7qZ0gJ/MRIVczo0"` returning `HTTP/1.1 304 Not Modified`.

### 7. `wireshark/` (Task G)
- `phase1-flow.pcap` & `tls12-handshake.pcap`: Packet capture recording complete flow (DNS on UDP 53, TCP 3-way handshake on 8443, TLS 1.2 handshake, and Application Data).
- `wireshark-packet-analysis.txt`: Step-by-step annotation covering IP addresses, ephemeral ports, Sequence/ACK numbers, TLS Record Layers, and 5-layer OSI/TCP-IP mapping.

### 8. `failures/` (Deliberate Failure Demonstrations)
- `failure-case-1-dns-resolver-failure.txt`: Case 1 - Misconfigured DNS resolver.
- `failure-case-2-dns-misdirection.txt`: Case 2 - DNS pointing to host without Edge service.
- `failure-case-3-single-backend-stopped.txt` & `backend-A-stopped.txt`: Case 3 - Backend failover.
- `failure-case-4-both-backends-down.txt`: Case 4 - Total backend failure (`502 Bad Gateway`).
- `failure-case-5-wrong-port.txt`: Case 5 - Wrong port test.

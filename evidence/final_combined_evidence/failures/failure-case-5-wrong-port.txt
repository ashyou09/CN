=== Diagnosis & Viva Defense ===
- Layer 3 (IP/ICMP) is healthy: Host is reachable via ping.
- Layer 4 (TCP Transport) fails: Target host returns a TCP RST packet because no service is listening on port 8444.
- Proves separation between IP address (Layer 3 Host Identifier) and Port number (Layer 4 Service Multiplexer).
- Remediation: Target port 8443 (HTTPS) or 8080 (HTTP).
